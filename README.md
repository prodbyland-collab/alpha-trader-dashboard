# Momentum Master

Build an AI crypto trading bot dashboard for momentum and volume breakout trading targeting 1-5% daily profits. Include a real-time crypto market scanner for volume spikes and breakout signals, exchange API management (with live execution and paper trading toggle), automated order triggers with customizable take-profit (1-5%) and stop-loss settings, active position tracking with live P&L, interactive price charts, and performance analytics.

This project was built with [Lovable](https://lovable.dev).
